## Qwen-Audio-3.0-TTS 文本正则化（TN）能力演示

简体中文 | [English](./README_EN.md)

**文本正则化（Text Normalization，TN）** 是语音合成把「书面形式」转换成「口语形式」的环节。数字、单位、符号、缩写都必须先展开成人类真正会说出的词，再交给声学模型发音。它是合成音频里最容易听出瑕疵的一环：

| 书面形式 | TN 失败时可能读成 | 正确的口语形式 |
| --- | --- | --- |
| `20%` | 二十**百分号** | 百分之二十 |
| `4～30` | 四**波浪线**三十 | 四**到**三十 |
| `965113` | 九十六万五千一百一十三 | 九六五一一三（逐位） |
| `150石` | 一百五十 **shí** | 一百五十 **dàn** |

本示例挑选了 3 段**刻意难读**的中文文本，密集包含数量词、生僻量词、多音字、百分号、全角波浪范围符、服务热线号码与时间量，用于直观感受 Qwen-Audio-3.0-TTS 的 TN 表现。

### :point_right: 三段测试文本与检查点

#### 一、古代官俸：数量词 + 生僻量词 + 多音字

> 正一品官，月领禄米150石，俸钱12万文，外加每年绫20匹，罗1匹，绵50两;从九品官，月禄米5石，俸钱8000文，加每年绵12两。

| 书面形式 | 应当听到 |
| --- | --- |
| `150石` | 一百五十石（**dàn**），作为容量单位不读 shí |
| `12万文` | 十二万文，万位要合并 |
| `1匹` | 一匹，量词前的 1 读「一」而非「幺」 |
| `;` | 半角分号也要当作句中停顿处理 |
| `8000文` | 八千文，不读「八零零零」 |

#### 二、医药检测：百分号 + 波浪范围符 + 单位

> 在一次检测中，1毫升20%甘露醇药液中可查出粒径4～30微米的微粒598个。

| 书面形式 | 应当听到 |
| --- | --- |
| `20%` | 百分之二十 |
| `4～30微米` | 四**到**三十微米，全角波浪号读作「到」，不能读出符号名 |
| `1毫升` | 一毫升 |
| `598个` | 五百九十八个 |

#### 三、服务热线：号码逐位读 + 时间量

> 965113供水服务热线24小时受理用户来电、来访、报修、报漏、投诉，做到用户反映的问题件件有落实、件件有反馈。

| 书面形式 | 应当听到 |
| --- | --- |
| `965113` | 九六五一一三，电话号码**逐位读** |
| `24小时` | 二十四小时，时间量按基数词读 |

### :point_right: 关于验证方式的说明

TN 效果**最终只能靠人耳判断**。多音字声调、数字分组读法这类差异，即使把合成音频再送回语音识别（ASR）也无法可靠区分——ASR 自带的逆正则化会把「百分之二十」还原写成 `20%`，声调差异更是不体现在文字上。

因此本示例不做自动断言，而是把每段文本里需要留意的位置整理成**检查点**打印在终端：运行时边听边对照即可。

> :bulb: 实测中，把生成音频送回 `paraformer-realtime-v2` 做回环，可以确认 `4～30微米` 被规范化为「四到三十微米」（识别结果为 `4到30微米`）；而第一段的文言词汇因 ASR 自身识别率有限，无法用这种方式判定，需要直接试听。
